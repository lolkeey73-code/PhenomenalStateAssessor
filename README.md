# Phenomenal State Assessor

[![DOI](https://img.shields.io/badge/DOI-10.6084/m9.figshare.30590597.v1-blue)](https://doi.org/10.6084/m9.figshare.30590597.v1)

A free 10-minute diagnostic tool that quantifies your conscious experience using the Ontological Theory of Self-Referential Differences.

## 🧠 What It Does

Phenomenal State Assessor evaluates your inner state through 5 scientifically-grounded parameters:

- **Integration (I)** - Coherence between thoughts, feelings, and body
- **Reflexivity (R)** - Meta-cognitive awareness and self-observation  
- **Differentiation (Δ)** - Richness of experiential states
- **Autonomy (C)** - Energetic independence from external validation
- **Tension (N)** - Level of internal stress and resistance

## 🚀 Quick Start

### For Users:
1. **Download** the latest release: [Download Now](https://github.com/PhenomenalStateAssessor/PhenomenalStateAssessor/releases/latest)
2. **Run** `PhenomenalStateAssessor.exe` (Windows)
3. **Complete** the 10-minute assessment
4. **Receive** your personalized improvement plan
